# Crafter

ComputerCraft (CC:Tweaked) storage + autocrafting for a Create modpack.

## brain_ui.lua - monitor interface (demo mode)

Touch interface for a **7 wide x 5 tall Advanced Monitor** (143 x 67 characters at text scale 0.5).
All data is simulated, so it runs without the vault program.

1. Advanced Computer with the 7x5 Advanced Monitor attached (touching it or through a wired modem).
2. Copy `brain_ui.lua` onto the computer (drag the file onto the computer screen).
3. Run `brain_ui`.

Right-click the monitor to use it. Keys on the computer:
`D` drop items, `F` fail next turtle batch, `U` unplug/replug silo_46, `P` palette, `S` speed, `R` reset, `Q` quit.
